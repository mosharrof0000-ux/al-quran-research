# Instruction — PROJECT_HISTORY.md

- ID: INST-PROJECT-HISTORY
- Class: A — Critical historical record
- Status: ACTIVE

## Purpose
Preserve the permanent technical and research history of the project.

## Rules
1. Never erase successful, failed, reverted, or superseded history merely for cleanup.
2. New history entries must identify date, change/problem, evidence, relevant files, result, and next step when applicable.
3. Historical commit SHAs and backup references must not be invented.
4. This file records history; current operational truth belongs in `PROJECT_STATE.md`.
5. Do not rewrite old entries to make history appear cleaner.
6. Any correction to historical wording should be additive and clearly identified.

## Verification
After editing, verify the new entry reflects an actual repository change and does not alter project assets.
