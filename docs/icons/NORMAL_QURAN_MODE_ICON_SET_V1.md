# Normal Quran Mode — Icon Set v1.0\n\n## Purpose\nThis icon set is the reference implementation for the সাধারণ কোরআন পাঠ / Normal Quran Mode. It is intentionally separate from future Sufi Mode assets.\n\n## Design rules\n- Minimalist, modern thin-line glyphs.\n- SVG, scalable, lightweight.\n- fill="none" and stroke="currentColor".\n- Stroke width target: 1.8–2px; v1 uses 1.9px.\n- Transparent background; color is inherited from the UI.\n- Standard UI concepts carry a subtle Quranic/Islamic motif.\n\n## 10 icons\n1. Quran / Main Book — open Quran on a Rehal/X-stand.\n2. Surah — Mihrab/arch frame.\n3. Ayah — eight-point Islamic star with center dot.\n4. Tafseer / Knowledge — Fanous/lantern with rays.\n5. Save / Bookmark — bookmark with dome/minaret curve.\n6. Audio / Tilawat — headphones with recitation-wave bars.\n7. Home Navigation — mosque dome/arch entrance.\n8. Search — magnifier with eight-point star inside lens.\n9. Like / Favorite — heart with geometric star detail.\n10. Share — sharing nodes connected by an arch-like geometry.\n\n## Usage\nThese assets are stored only in v1.0. They are not automatically wired into the live reader yet. A later integration must follow: Backup → isolated integration → visual/mobile verification → approval → live deployment.\n\n## Mode separation\nNormal Mode uses this set. Sufi Mode must have a separate asset namespace and manifest so changing modes never overwrites or mutates Normal Mode assets.\n\n## Reference\nThe 10-icon design sheet supplied/generated for this work is the visual reference for this set. Future revisions should be versioned rather than overwriting v1.0.\n
