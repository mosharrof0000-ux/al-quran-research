# Instruction — AGENT_HANDOFF_PROTOCOL.md

## Purpose
Govern transfer of incomplete Project Agent work.

## Rules
- Handoff is mandatory for blocked, paused, incomplete, or transferred work.
- Successors receive new identities.
- Predecessor history is never erased.
- Successors independently verify inherited claims when practical.
- Handoff never authorizes merge or deployment.

## Verification
Check predecessor/successor IDs, remaining work, changed files, commits, tests, limitations, and next action.

## Status
ACTIVE on this safety branch; promotion requires normal governance review.
