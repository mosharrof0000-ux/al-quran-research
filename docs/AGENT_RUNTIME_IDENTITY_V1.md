## Runtime contract
Every Project Agent request receives:
- task_id — persistent work identity supplied by caller or generated by the Worker
- session_id — unique execution/session identity
- agent_name — Bengali project identity label
- status — READY_FOR_REVIEW on successful execution; BLOCKED on failure
- handoff_required — true until the work is explicitly reviewed and handed off

## Safety
- Production main remains untouched.
- Project Agent remains isolated.
- Merge/deploy remain unavailable to the agent.
- A failed request is recorded as BLOCKED rather than falsely reported complete.

## Continuation
A successor must preserve the original task/agent identity and create a new identity for its own work. The two records must remain separately traceable.
