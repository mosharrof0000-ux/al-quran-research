# Instruction — AGENT_WORK_LEDGER.md

## Purpose
Govern persistent task/work records for Project Agents.

## Rules
- Record actual work, not imagined or inferred work.
- Keep verification and deployment states separate.
- Preserve predecessor/successor chains.
- Do not store credentials, tokens, or hidden chain-of-thought.
- Do not mark a task LIVE_VERIFIED without live evidence.

## Verification
Check required fields, status transitions, branch/commit references, and evidence claims.

## Status
ACTIVE on this safety branch; promotion requires normal governance review.
