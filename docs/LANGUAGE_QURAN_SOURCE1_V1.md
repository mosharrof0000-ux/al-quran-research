# Source 1 — ভাষাভিত্তিক কুরআন

Status: INSTALLED-V1 / REVIEW REQUIRED

Source 1 is the project's language-research edition. It is a provenance-preserving composite; it does not overwrite or merge the original source texts.

## Components
1. Arabic base — Tanzil Uthmani, Version 1.1. Tanzil permits verbatim redistribution with attribution and a link to tanzil.net; changing the text is not permitted.
2. Bengali meaning — QuranEnc, Abu Bakr Zakaria Bengali translation. The provider's publication/version terms must remain attached to the source record.
3. Bengali pronunciation — Anis Afifi Multilingual Quran Dataset, field transliteration_bn. The project keeps this provenance separate because the underlying transliteration provenance is not yet fully established.
4. Linguistic analysis layer — Quranic Arabic Corpus v0.4: morphology, syntax and related linguistic annotation. The corpus permits website/application use with source attribution and link, under its stated GNU license terms.

## Integrity rules
- Source 1 is a distinct edition/context, not a claim that the underlying component texts are newly authored by the project.
- Component data are not silently rewritten or mixed into a new raw source.
- Research claims must retain source/version/evidence provenance.
- Islamic Foundation Bangladesh material is not included here; it remains separately private/locked pending permission verification.
- The Reader must not label Source 1 component data as Project-Verified research data.

## Initial Reader behavior
Selecting Source 1 now opens the Reader and loads the full 114-surah/6,236-ayah reading context using the verified component endpoints already present in the project. The header explicitly identifies Source 1 so it is not confused with Source 2.
