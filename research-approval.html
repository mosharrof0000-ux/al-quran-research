Approval Interface — AI প্রস্তাব → মানব অনুমোদন → নতুন Version
চ্যাটে ফিরুন
১
AI-এর PENDING_REVIEW প্রস্তাব এখানে দিন
গবেষণা চ্যাট থেকে পাওয়া research_record_proposal JSON এখানে বসান। এই পেজ নিজে কোনো GitHub লেখা বা অনুমোদন করে না।
এখনও কোনো প্রস্তাব যাচাই করা হয়নি।
২
অনুমোদনের আগে সারাংশ পরীক্ষা করুন
নিচের পরিচয়গুলো মিলিয়ে নিন। ভুল/অজানা তথ্য থাকলে অনুমোদন করবেন না।
৩
মানব অনুমোদন দিন
প্রস্তাব যাচাইয়ে PASS হলে GitHub Actions-এর নির্ধারিত Approval Workflow খুলুন। সেখানে একই JSON এবং অনুমোদন শব্দ APPROVE দিতে হবে। Workflow নিজে সর্বশেষ Version বের করবে, পুরোনো Version অক্ষত রাখবে এবং Master Dataset পরিবর্তন করবে না।
Approval Workflow খুলুননিয়ম দেখুন
৪
অনুমোদনের পরে
নতুন Version তৈরি হলে আগের Version মুছে যাবে না। নতুন রেকর্ডে supersedes দিয়ে আগের রেকর্ডের পরিচয় থাকবে। VERIFIED status কেবল মানব Approval Workflow-এর মাধ্যমে সেট হবে।
