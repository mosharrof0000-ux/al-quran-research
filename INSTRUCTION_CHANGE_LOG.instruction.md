# Instruction — INSTRUCTION_CHANGE_LOG.md

- ID: INST-INSTRUCTION-CHANGE-LOG
- Class: P0 — Critical governance history
- Status: ACTIVE

## Purpose
Preserve a traceable history of changes to the instruction and governance system.

## Rules
1. Record meaningful instruction creation, migration, update, supersession, and audit events.
2. Include date, affected instruction/path, reason, evidence or commit when available, and result.
3. Do not rewrite old entries to hide failures or uncertainty.
4. Distinguish proposals from applied governance changes.

## Verification
Each new entry must correspond to an actual repository change or documented governance decision.

## Update Trigger
Any material instruction-system or governance change.
