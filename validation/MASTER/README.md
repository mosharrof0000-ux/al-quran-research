# Validation Folder Master

## Purpose
Verification records and validation definitions for research data and project behavior.

## Rules
- Validation is separate from raw data.
- A validation result must identify what was checked and its status.
- Failed or uncertain validation must remain visible; do not overwrite raw evidence.
- Promotion requires the project's verification gate.

## File Map
- `pilot_validation.md` — current pilot validation record.
