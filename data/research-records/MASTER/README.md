# Research Records Folder Master

## Purpose
Controlled storage boundary for individual Qur'an research records.

## Dictionary-First Rule
Records should be addressable by stable Research ID and, where applicable, by Arabic word, lemma, and root. Word-level dictionary identity must remain linked to ayah usage rather than duplicating conflicting raw data.

## Rules
- Never overwrite an existing raw research record.
- Corrections create a new version/proposal.
- Keep Research ID stable and traceable.
- Preserve source, confidence, verification state, and history.
- Do not publish a record as Verified without evidence and validation.
- This local Master cannot override root governance.

## Planned Record Axes
Research ID → Word → Lemma → Root → Morphology → Grammar → Meaning Range → Ayah Occurrences → Context → Evidence → Analysis → Version History.

## Status
Governed boundary established on 2026-09-13; record inventory is currently empty/being populated.
