# Dictionary Master — অভিধানভিত্তিক গবেষণা কাঠামো

## উদ্দেশ্য
কুরআনের ভাষাভিত্তিক গবেষণার কেন্দ্রীয় অভিধান-স্তর। একই আরবি শব্দ বিভিন্ন আয়াতে ব্যবহৃত হলেও তার শব্দ-পরিচয় একবার সংজ্ঞায়িত হবে এবং ব্যবহারগুলো আয়াতের সঙ্গে সংযুক্ত থাকবে।

## মূল পরিচয়-শৃঙ্খল
আরবি শব্দ → Lemma → Root → শব্দরূপ/মরফোলজি → ব্যাকরণ → অর্থের পরিসর → কুরআনে ব্যবহার → আয়াত → প্রসঙ্গ → প্রমাণ → গবেষণা/বিশ্লেষণ → সংস্করণ ইতিহাস।

## নীতিমালা
- Raw source ও verified/derived তথ্য আলাদা থাকবে।
- একই শব্দের পুনরাবৃত্ত ব্যবহার নতুন অভিধান-সত্তা নয়; occurrence হিসেবে যুক্ত হবে।
- Root বা Lemma নির্ধারণে অনিশ্চয়তা থাকলে তা OPEN/Disputed হিসেবে থাকবে।
- কোনো অর্থকে কেবল AI-এর অনুমানের ভিত্তিতে Verified করা যাবে না।
- প্রতিটি প্রকাশযোগ্য সিদ্ধান্তের traceable evidence থাকতে হবে।
- বিদ্যমান `data/fatiha*.json` বা অন্য গবেষণা ফাইল সরানো/ওভাররাইট করা যাবে না; আগে mapping ও dependency verification হবে।

## ভবিষ্যৎ অভিধান উপ-স্তর
`roots/` · `lemmas/` · `words/` · `occurrences/` · `meanings/` · `grammar/` · `evidence/`

এই উপ-স্তরগুলো প্রয়োজন অনুযায়ী তৈরি হবে; এখনই বিদ্যমান ডেটা স্থানান্তর করা বাধ্যতামূলক নয়।
