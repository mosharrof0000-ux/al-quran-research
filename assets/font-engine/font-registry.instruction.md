# Font Registry Instruction

- Path: `assets/font-engine/font-registry.json`
- Purpose: registry for approved/future typography assets and presentation metadata.
- Scope: presentation configuration only; never Quran/data semantics.
- Allowed: add versioned font records, weights, styles, files, licenses and future presentation metadata.
- Forbidden: modifying Quran text, research records, APIs or protected data.
- Verification: valid JSON, registry references valid, provenance/license recorded.
- Update trigger: any registry schema or asset change.
- Status: ACTIVE under Front Font & Text Engine v1.
