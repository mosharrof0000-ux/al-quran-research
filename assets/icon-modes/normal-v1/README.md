# Normal Quran Mode — Icon Set v1

Purpose: store the default Quran reading mode icon set. Style: minimalist Islamic/Quranic line-art, monochrome, transparent background, currentColor, stroke-width 1.8.

Icons: Quran/Rehal, Surah/Mihrab, Ayah/Rub el Hizb, Tafseer/Fanous, Bookmark/Minaret dome, Audio/Tilawat, Home/Mosque arch, Search/8-point star, Favorite/Geometric heart, Share/Arch nodes.

Usage rules:
- These assets are for Normal Quran Mode only.
- Future Sufi Quran Mode must have a separate directory and manifest.
- Do not replace Normal Mode assets with Sufi assets.
- Do not connect this set to the live Reader until visual review and mode-switch integration testing are complete.
- Preserve fill="none" and stroke="currentColor".

Versioning: corrections must create a new version; do not silently overwrite approved geometry.
