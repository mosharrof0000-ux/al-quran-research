# Normal Quran Reader Icon Set v1

Status: STORED / NOT LIVE-WIRED.

This is the default visual icon set for the **সাধারণ কোরআন মোড**. It follows the supplied 10-icon reference: Quran on rehal, mihrab Surah, Rub el Hizb Ayah, fanous knowledge, minaret-dome bookmark, tilawat headphones, mosque gateway home, star search, geometric heart, and arch share.

## Design contract
- Minimalist thin line-art.
- SVG with transparent background.
- `fill="none"`, `stroke="currentColor"`, stroke-width 2.
- Recolorable and scalable.
- This namespace is independent from future Sufi Mode assets.

## Usage
Use these assets only when Reader mode = `normal-quran`. Do not modify Quran text/data when switching modes. Sufi Mode must have its own namespace and design registry.

## Integration gate
Backup → Demo → Review → Approve → Icon Engine integration → Mobile/Light/Night verification → Live deployment → Document result.
