# Normal Quran Reader Icon Set v1

Production-ready monochrome SVG reference set for সাধারণ কোরআন মোড.

Design: minimalist Islamic/Quranic line-art, fill=none, stroke=currentColor, nominal stroke-width=1.9px, viewBox 0 0 64 64, round caps/joins, no external icon dependency.

Files: quran, surah, ayah, tafseer, bookmark, audio-tilawat, home, search, favorite, share.

Use only when the active reader mode is normal-quran. Sufi Mode must use a separate versioned asset namespace.

This package is an asset/reference layer only. It does not modify Quran text, translations, research data, database, or routing.
